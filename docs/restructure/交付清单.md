### 阶段 1: 学习理解（1-2小时）

```
1. 阅读项目根目录的《目录结构优化指南.md》
   ↓
2. 阅读 docs/restructure/README.md
   ↓
3. 阅读 RESTRUCTURE_README.md（总览）
   ↓
4. 阅读 STRUCTURE_COMPARISON.md（对比）
   ↓
5. 浏览 DIRECTORY_STRUCTURE_OPTIMIZATION.md（完整方案）
```

### 阶段 2: 准备工作（15-30分钟）

```
1. 确保所有更改已提交
   ↓
2. 创建备份分支
   ↓
3. 创建开发分支
   ↓
4. 准备 QUICK_REFERENCE.md（随时查阅）
```

### 阶段 3: 执行迁移（5-6小时）

```
方式 A: 使用自动化脚本（推荐）
./scripts/migrate-structure.sh --all
  ↓
手动更新导入路径
  ↓
验证和测试

方式 B: 手动执行
按照 MIGRATION_GUIDE.md 逐步执行
  ↓
参考 QUICK_REFERENCE.md 查阅路径
  ↓
每个阶段后测试
```

### 阶段 4: 验证测试（1-2小时）

```
1. 运行开发服务器
   ↓
2. 测试所有功能
   ↓
3. 运行 lint 和测试
   ↓
4. 构建检查
   ↓
5. 性能测试
```

### 阶段 5: 完成收尾（30分钟）

```
1. 更新项目文档
   ↓

   ↓

   ↓

```
